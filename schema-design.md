## MySQL Database Design

### Table: patients
- id: BIGINT, Primary Key, Auto Increment
- name: VARCHAR(100), Not Null
- email: VARCHAR(255), Not Null, Unique
- password: VARCHAR(255), Not Null
- phone: VARCHAR(10), Not Null
- address: VARCHAR(255), Not Null

### Table: doctors
- id: BIGINT, Primary Key, Auto Increment
- name: VARCHAR(100), Not Null
- specialty: VARCHAR(50), Not Null
- email: VARCHAR(255), Not Null, Unique
- password: VARCHAR(255), Not Null
- phone: VARCHAR(10), Not Null

### Table: doctor_available_times
- doctor_id: BIGINT, Not Null, Foreign Key → doctors(id)
- available_times: VARCHAR(50), Not Null (e.g. "09:00-10:00")

_Note: generated by `@ElementCollection` on `Doctor.availableTimes`. One row per time slot of each doctor; it is not an entity on its own._

### Table: appointments
- id: BIGINT, Primary Key, Auto Increment
- doctor_id: BIGINT, Not Null, Foreign Key → doctors(id)
- patient_id: BIGINT, Not Null, Foreign Key → patients(id)
- appointment_time: DATETIME, Not Null
- status: INT, Not Null, Default 0 (0 = Scheduled, 1 = Completed, 2 = Cancelled)

### Table: admin
- id: BIGINT, Primary Key, Auto Increment
- username: VARCHAR(20), Not Null, Unique
- password: VARCHAR(255), Not Null

## MongoDB Collection Design

### Collection: prescriptions
```json
{
  "_id": "ObjectId('64abc123456')",
  "patientName": "John Smith",
  "appointmentId": 51,
  "medication": "Paracetamol",
  "dosage": "500mg every 6 hours",
  "doctorNotes": "Take after meals.",
  "refillCount": 2,
  "pharmacy": {
    "name": "Walgreens SF",
    "location": "Market Street"
  }
}
```
- `patientName`: required, 3–100 characters
- `appointmentId`: required, references `appointments.id` in MySQL
- `medication`: required, 3–100 characters
- `dosage`: required
- `doctorNotes`: optional, max 200 characters
